# Attendance Generator

שלד ראשוני לפרויקט Python לעיבוד דוחות נוכחות וליצירת דוחות סינתטיים.

## מה כבר קיים
- מודלים כלליים לנתונים שחולצו ממסמך.
- הערכת איכות החילוץ והחלטה אם להמשיך אוטומטית או להעביר לבדיקה אנושית.
- בדיקות אוטומטיות למודלים ולמנגנון ההחלטה.

## מה עדיין לא קיים
OCR, זיהוי סוג דוח, parsers ייעודיים, יצירת וריאציות, יצירת PDF וייצוא JSON.
נוסיף אותם לאחר שנאמת את מבנה הדוחות וכללי החישוב מתוך קובצי המקור המלאים.

## התקנה ב-Windows PowerShell
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install --upgrade pip
py -m pip install -e ".[dev]"
```

## בדיקות
```powershell
py -m pytest
```

## עקרון התכנון
ציון OCR אינו הוכחה לנכונות. ההחלטה משלבת ביטחון זיהוי, שדות חובה ובדיקות תקינות.
הספים בקוד הם ערכי התחלה בלבד ויש לכייל אותם מול דוחות אמיתיים.
